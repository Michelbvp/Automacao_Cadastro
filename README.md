# Automação de Cadastro
projeto desenvolvido na Jornada Python da Hashtag (28/09/2026)

# O que o projeto faz: 
Automação de cadastro de produtos em um sistema web.

# Tecnologias utilizadas: 
Python, Pandas, Openpyxl e PyAutoGUI.

# Como executar: 
Instruções para instalar os pacotes (pip install pandas openpyxl pyautogui) e rodar o script.

# Observações:
Trata-se do primeiro script da aula 1/4 da Jornada Python da Hashtag.
